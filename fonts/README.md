# Custom Fonts Directory

Any TrueType (`.ttf`) or OpenType (`.otf`) font placed in this directory is automatically discovered and made available across the certificate generator system:
- In the **Streamlit Web Dashboard** (`app.py`)
- In the **CustomTkinter Desktop App** (`gui.py`)
- In the **Python Engine** (`script.py`)

## Pre-installed Fonts:
- `Calligraffitti-Regular.ttf`: Calligraffitti font for elegant calligraphy certificates.
